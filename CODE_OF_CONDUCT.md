# Código de conducta

Queremos una comunidad respetuosa, segura y útil para personas de cualquier nivel de experiencia.

## Nuestro compromiso

Quienes participan se comprometen a comunicarse con respeto, recibir críticas técnicas de buena fe y priorizar la seguridad de las personas usuarias.

## Comportamiento esperado

- Explicar desacuerdos con evidencia y sin ataques personales.
- Ayudar a quienes están aprendiendo.
- Respetar la privacidad y no publicar datos sensibles.
- Aceptar decisiones de mantenimiento documentadas.

No se toleran acoso, discriminación, amenazas, divulgación de información privada ni explotación irresponsable de vulnerabilidades.

Las conductas inaceptables pueden reportarse de forma privada mediante GitHub Security Advisories. El mantenimiento podrá editar o retirar contribuciones y limitar la participación para proteger a la comunidad.
