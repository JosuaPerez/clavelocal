# ClaveLocal 0.6.1 · Interfaz renovada

Versión experimental para Windows x64. Sin auditoría independiente.

- **Nuevo aspecto.** Paleta de grafito y latón con tema claro u oscuro según tu sistema, más contraste y textos más grandes.
- **Más espacio.** La app ocupa toda la ventana, el menú lateral queda fijo y la lista muestra diez contraseñas por página.
- **Campos de clave.** Se corrige el icono de ojo duplicado.
- **Versión visible.** Ayuda y la ventana de actualizaciones muestran la versión instalada.
- **Accesibilidad.** Foco visible en todos los controles y menos animaciones si tu sistema lo pide.

El formato de la bóveda (`clavelocal-v1`) no cambia: las bóvedas existentes se abren con su clave actual y no hay migración. Para actualizar, abre ClaveLocal y pulsa **Buscar actualizaciones**. Exporta una copia cifrada antes de instalar y usa la misma cuenta de Windows.

La firma del actualizador se comprueba antes de ejecutar el instalador. El instalador todavía carece de firma de editor Authenticode y Windows puede mostrar un aviso.
